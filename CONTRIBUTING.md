\# Contributing to NoticeSense



\## Project Structure



NoticeSense is organized into separate backend, frontend, and static components.



\### Backend

\- `backend/api/` - FastAPI application and API routes

\- `backend/agents.py` - AI agent definitions

\- `backend/router/` - Agent routing and orchestration

\- `backend/services/` - OCR and notice parsing services

\- `backend/core/` - Application configuration

\- `backend/utils/` - Utility functions



\### Frontend

\- `frontend/app.py` - Frontend application entry point

\- `frontend/pages/` - Dashboard, chat, and about pages

\- `frontend/styles.py` - Frontend styling



\### Static

\- `static/index.html` - Web interface

\- `static/css/` - Stylesheets

\- `static/js/` - Frontend JavaScript



\## Development



1\. Clone the repository.

2\. Install the required Python dependencies from `requirements.txt`.

3\. Configure the required environment variables.

4\. Run the backend and frontend according to the project setup.

5\. Test changes locally before creating a commit.



\## Contribution Guidelines



\- Keep changes focused and related to the project.

\- Follow the existing project structure.

\- Avoid committing secrets or API keys.

\- Write clear commit messages.

\- Test changes before pushing them to the repository.
